# Nanhe

**नन्हे — little ones.** A premium, India-first baby skincare and toiletries
line: natural ingredients, clinically tested.

This repo holds the brand identity, the packaging for the first nine products,
AI photo renders and the brand book.

- Brand book: `brand-book/index.html` (open in a browser)
- Logos and packaging: `assets/` (SVG source files)
- Product line and claims: `docs/product/`
- Design decisions and render prompts: `docs/design/`

The brand book is a single static HTML page with inline SVG and Google Fonts —
no build step.

Agents: read `AGENTS.md`, then `CONTEXT.md`.
